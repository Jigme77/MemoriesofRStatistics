Interpreting Statistical Results

What do p-values, confidence intervals, and effect sizes actually mean? Explained for each test.

📌
Remember: A p-value below 0.05 means the result is statistically significant — but this does not automatically mean it is clinically important. Always consider effect size and biological context.

📊 P-values — What they mean

The p-value is the probability of observing your results (or more extreme) if there were truly no difference.

p-valueInterpretation
p < 0.05Statistically significant. Reject H₀.
p = 0.05–0.10Borderline — report with caution.
p > 0.10Not significant. Retain H₀.

📏 Confidence Intervals (CI)

A 95% CI means: if we repeated the experiment 100 times, the true value would fall within this range ~95 times.

t.test(weight ~ breed, data = cattle) # Output: 95% CI: [0.08, 0.34] kg

Key rule: If a 95% CI for a difference does not include 0 → statistically significant (p < 0.05).

🎯 Effect Size — Clinical relevance

Statistical significance ≠ clinical importance. Always report effect size alongside p.

MeasureSmallMediumLarge
Cohen's d (t-test)0.20.50.8
η² (ANOVA)0.010.060.14
Cramér's V (χ²)0.10.30.5

🐄 t-test Output — Reading it

t = 3.12, df = 18, p = 0.006 95% CI: [0.05, 0.28] Mean Angus = 1.53, Mean Hereford = 1.31

✔ Significant (p = 0.006 < 0.05). Angus cattle gained significantly more weight than Hereford (mean diff 0.22 kg/day). The 95% CI [0.05, 0.28] does not include 0, confirming this.

🐔 ANOVA Output — Reading it

Df Sum Sq Mean Sq F value Pr(>F) housing 2 24.3 12.15 8.74 0.0018 ** Residuals 17 23.6 1.39

✔ Significant (p = 0.002). Housing type significantly affects cortisol. The F-statistic compares between-group variance to within-group variance. Use TukeyHSD() to identify which pairs differ.

🐕 Kruskal-Wallis — Reading it

Kruskal-Wallis chi-squared = 8.14, df = 2 p-value = 0.017

✔ Significant (p = 0.017). Pain scores differ significantly across treatment groups. This is the non-parametric ANOVA — it tests whether the distributions differ, not the means. Follow up with Dunn's test for pairwise comparisons.

🐾 Chi-square — Reading it

X-squared = 5.88, df = 1, p-value = 0.015 Expected freq: all > 5 ✓

✔ Significant (p = 0.015). There is a significant association between breed and hip dysplasia. Check expected frequencies (>5 per cell) to ensure the test is valid. If any <5, use Fisher's Exact instead.

📈 Linear Regression — Reading it

Coefficients: Estimate Std.Error t value Pr(>|t|) (Intercept) 5.82 2.14 2.72 0.009 feed 1.68 0.31 5.42 <0.001 *** age 0.95 0.22 4.32 0.001 ** R-squared: 0.84

R² = 0.84 → feed and age explain 84% of variation in milk yield. For each kg increase in feed, yield increases by 1.68 L. Both predictors are significant (p < 0.001).

🦠 Logistic Regression — Reading it

Coefficients (log-odds): weight: -0.042 (OR = 0.959) temp: 0.381 (OR = 1.463)

Odds ratios (OR): For each 1 kg increase in weight, BRD odds decrease by 4%. For each 1°F increase in temperature, BRD odds increase by 46%. Report with 95% CI for OR. OR > 1 = increased risk; OR < 1 = protective.

⏱️ Kaplan-Meier — Reading it

Call: survfit(Surv(time, status) ~ treatment) n events median 0.95LCL 0.95UCL Tx A: 20 16 120 95 145 Tx B: 20 11 210 175 255 log-rank p = 0.031

✔ Significant (p = 0.031). Median survival in Tx B (210 days) was significantly longer than Tx A (120 days). The log-rank test compares the full survival curves, accounting for censored observations.

Common Mistakes to Avoid

❌ Using t-test for non-normal data

Always check normality first (Shapiro-Wilk test or Q-Q plot). If violated with small samples, use Mann-Whitney U instead.

shapiro.test(cattle$weight_gain) # p > 0.05 → normality OK

❌ Multiple t-tests instead of ANOVA

Comparing 3+ groups with repeated t-tests inflates Type I error. With 3 groups at α=0.05, true error rate rises to ~14%. Use ANOVA + Tukey correction.

❌ Ignoring small expected counts in χ²

If any expected cell frequency <5, Chi-square is unreliable. Switch to Fisher's Exact Test, especially with small veterinary samples.

⚠️ p < 0.05 ≠ clinically meaningful

A large sample can make trivial differences significant. Always report effect size (Cohen's d, OR, R²) and ask: does this difference matter in practice?

Each bar represents the mean weight gain (kg/day) for each breed. Error bars show ±1 standard deviation. A non-overlapping pattern suggests a real difference — confirm with a t-test.

📈 Scatter plot — Feed intake vs Milk yield
📋 How to read this

Each point is one cow. The trend line shows a positive linear relationship: as feed intake increases, milk yield increases. This motivates using linear regression to quantify the relationship.

🎻 Box plot — Cortisol by Housing Type
📋 How to read this

The box spans the IQR (25th–75th percentile). The line inside is the median. Dots beyond whiskers are outliers. Overlapping boxes suggest no difference; separated boxes suggest a significant one — test with ANOVA.

### R Analysis Template
# 1. Load data
data <- read.csv("your_file.csv")

# 2. Explore
str(data); summary(data)

# 3. Check normality
shapiro.test(data$outcome)

# 4. Run test
result <- t.test(outcome ~ group, data = data)
print(result)

# 5. Effect size
library(effectsize)
cohens_d(outcome ~ group, data = data)

# 6. Plot
boxplot(outcome ~ group, data = data)

Week 3

Week 5

Linear regression. Use milk_yield.csv. Coefficients, R², residual diagnostics. Difference from correlation.

Week 6

Logistic regression + survival. BRD risk model and Kaplan-Meier curves. Binary outcomes, odds ratios, censoring concept.

🚧 Common Student Difficulties
Pitfall 1

Normality assumption. Students often skip Shapiro-Wilk. Use the flowchart's normality node. Emphasise: with n <30, normality matters most.

Pitfall 2

Multiple testing. Students run 3+ t-tests across group pairs. Clarify ANOVA's role and Tukey's HSD for post-hoc comparisons.

Pitfall 3

Over-reliance on p-value. Students report p alone. Require effect size and CI in all assignments. Use the "p < 0.05 ≠ important" discussion.
